# Code of Conduct

WinterSolve should be a welcoming open-source project for developers of different skill levels, backgrounds, and communities.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent.
- Give feedback that helps the project improve.
- Make space for beginners.
- Keep discussions focused on the work.

## Unacceptable Behavior

- Harassment or personal attacks
- Discrimination
- Public shaming
- Spam or intentionally disruptive behavior
- Sharing private information without consent

## Reporting

If there is a problem, project maintainers should review the situation fairly and take action that protects the health of the community.
