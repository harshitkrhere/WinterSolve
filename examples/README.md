# Examples

| File | What it is |
| --- | --- |
| [`sample-reports/wintersolve-repo-brain.md`](sample-reports/wintersolve-repo-brain.md) | Real `wintersolve brain . --format markdown` output for this repository. |
| [`sample-reports/wintersolve-repo-brain.json`](sample-reports/wintersolve-repo-brain.json) | The same report as JSON (`schema_version` 1), the shape integrations consume. |
| [`github-action.yml`](github-action.yml) | Drop-in workflow that posts a Repo Brain report to the Actions job summary on every push. |

The sample reports are regenerated by hand at release time; the absolute path
is replaced with `/home/dev/WinterSolve` so the files are the same on every
machine. To produce your own:

```bash
wintersolve brain . --format markdown --output repo-brain.md
wintersolve brain . --format json --output repo-brain.json
```
