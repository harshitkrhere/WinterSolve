# Support

WinterSolve is a volunteer-maintained open-source project. There is no
commercial support, but questions are welcome.

## Where to ask

| Need | Go to |
| --- | --- |
| A wrong, confusing, or crashing result | [Bug report](https://github.com/harshitkrhere/WinterSolve/issues/new?template=bug_report.md) |
| A new detector, command, or output | [Feature request](https://github.com/harshitkrhere/WinterSolve/issues/new?template=feature_request.md) |
| "How do I..." or "would this fit?" | [Discussions](https://github.com/harshitkrhere/WinterSolve/discussions) |
| A security problem | [SECURITY.md](SECURITY.md) (never a public issue) |

## What to include

- `wintersolve --version`, your OS, and `python --version`.
- The exact command you ran.
- The output, or the part that was wrong. WinterSolve redacts secrets, but
  please look once more before pasting.
- For detection bugs, the relevant file (a manifest, a README snippet, an
  error message). A tiny folder layout that reproduces it is gold.

## Supported versions

The latest release gets fixes. Older releases do not; please upgrade first.

| Version | Status |
| --- | --- |
| 0.3.x | Current |
| 0.2.x and earlier | Unreleased internal milestones |

## Self-help

- `wintersolve --help` and `wintersolve <command> --help` list every option.
- [docs/COMMANDS.md](docs/COMMANDS.md) explains exit codes and the JSON format.
- [docs/INSTALLATION.md](docs/INSTALLATION.md) covers PATH problems and Windows.
