# Support

WinterSolve is an open-source project and does not currently provide commercial support.

## Getting Help

- Use GitHub issues for reproducible bugs and feature requests.
- Include the WinterSolve version, operating system, Python version, command used, and relevant sanitized output.
- Use discussions or issues for workflow ideas before large changes.

## Supported Versions

WinterSolve is currently alpha software. The latest release receives fixes and improvements.

| Version | Status |
| --- | --- |
| 0.2.x | Active alpha |
| 0.1.x | Historical |

## Security Issues

Do not open public issues for vulnerabilities or exposed secrets. Follow `SECURITY.md`.
